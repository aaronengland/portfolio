Basic Python library to demo hosting and installing a python library on Github.

---

To install locally:

1. Clone this repository:
```
git clone https://<YOUR_GITHUB_PERSONAL_ACCESS_TOKEN>@github.com/PFS-Risk-DS/my_library.git
```

2. Navigate to the directory containing the ```setup.py``` file

3. Install in Editable Mode:
```
pip install -e .
```

---

To install from Github:

1. Use pip
```
pip install git+https://<YOUR_GITHUB_PERSONAL_ACCESS_TOKEN>@github.com/PFS-Risk-DS/my_library.git
```
