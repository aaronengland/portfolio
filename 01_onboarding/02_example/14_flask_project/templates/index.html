Python

Python is crucial to the flow of business as it is one of the easiest coding languages to use and has a ton of data manipulation functionalities that are extremely useful in the data science field. Python is filled with libraries that can be used for data manipulation, some of these libraries you will be using include NumPy and Pandas. Your knowledge of these libraries will be put to the test. SQL

Structured Querey Language (SQL) is another important piece of the business. We use it to extract data from databases which is the first step of data analysis and its functionalities allow us to filter, aggregate, join, and transform data to gather exactly what we're looking for before futher inspection can be done. AWS

Amazon Web Services (AWS) is a cloud platform that provides an extensive array of computing resources over the cloud. It is a semi-newly adopted technology that has been monumental in improving the efficency and power capability of the business. Some of the service categories that AWS offers include Computing Power, Storage, Databases, Networking, Machine Learning, Analytics and more. One of the main advantages that is gained from using AWS is the Scalability of power that can be utilized. It is important to have this scalabilty when dealing with large amounts of data as doing so on the local side can take exceptionally longer and in some cases break all together.

Below we will dive deeper into some of these services that you will become deeply familar with

SageMaker

SageMaker is a service that streamlines the machine learning workflow, from building and training to deploying models at scale. It's connected devellopment hub, SageMaker Studio, Utilizes Jupyter Notebooks for data exploration and model development. Its capability for scale is not to be under sold, you can go from the ml.t3.medium with 2 vCPU's and 4GiB's of memory. all the way up to a ml.g5.48xlarge with 192 vCPU's and 768 GiB's of memory. Of of this computing power is instantly accessible making it seamless for handing the smallest and the largest of datasets in seconds.

S3

S3 is the storage solution for all of AWS, It is capable of housing large amounts of data and is seamlessly integrated into every part of AWS allowing for storing and retrieving data anywhere. It has a user-friendly design makes it very easy to understand and gives you an easy way to copy and paste the URI to point to the bucket when you will eventually be pulling data from it to do research.

The next three topics all join together with SageMaker and S3 to preform tasks together seamlessly.

Batch

Batch is a tool used to schedule computing workloads and automatically scales resources based on the size of the job. It uses job queues to organize job scheduling and manages the execution of the job definition. Batch supports parallel execution, significantly reducing the time it takes to run larger jobs, such as machine learning on bigger data sets. When combined with the other features of AWS, it can further enhance these processes.

Lambda

Lambda takes the code that you write and automatically handles the execution, scaling, and maintenance of the computation. It has event-driven execution where functions can be triggered by changes in data, user requests, or system states. It is joined with Batch in sectioning out larger portions of information and running them in tandem to work through large amounts of data that would have taken hours to process and get through all of it in a matter of minutes drastically improving efficiency without cutting any of the effectiveness.

Step-Functions

Step-Functions combine both of these features (and can be combined with others as well) to link up the jobs and again improve efficiency. You can set up a Step-Function to go in order of processes that you design and process them in steps to ensure the flow of work is seamless. For more information about Step-Functions click here.

Flask

Flask is a versatile web framework for Python designed to create web applications quickly. I used it to develop the webpage you're currently viewing! Known for its simplicity and minimalism, it's easy to use even for novice web developers. It can also utilize Python capabilities like Plotly to display graphs on a webpage in a user-friendly manner.

GitHub

GitHub is a web-based platform that is used for collaborative software development. At its core, it has repositories where projects and their files are stored and can be public or private. GitHub uses Git, which allows people to work on a project at the same time without overwriting each other's work. It supports collaboration through team management, project boards, discussions, and code reviews. We can use git to clone repositories to our local machines to develop on top of the work that has been done. It is important to remember that Pulling in information is always the first step before uploading any changes you made, to ensure you don't overwrite the work that could have been done to the repository before committing and pushing the new information through to GitHub.
